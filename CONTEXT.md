# Linaria demo project

Мини-проект для подготовки к собеседованию: один UI-компонент, собранный как библиотека.

## Language

**Bundler (сборщик)**:
Инструмент, который склеивает исходники в файлы для браузера или для публикации.
_Avoid_: компилятор

**Rollup**:
Bundler, заточенный под библиотеки: выдаёт чистые ES-модули и хорошо делает tree-shaking.

**Rolldown**:
Bundler на Rust с API, совместимым с Rollup. Начиная с Vite 8, Vite собирает продакшен им, а не Rollup.

**Tree-shaking**:
Удаление из сборки кода, который никто не импортирует.

**Library mode**:
Режим сборки, где результат — пакет для `import` в чужом проекте, а не сайт.
_Avoid_: «собрать как модуль»

**CSS Modules**:
Обычный CSS-файл, у которого сборщик переименовывает классы в уникальные, чтобы стили разных компонентов не конфликтовали.

**Runtime CSS-in-JS**:
Стили пишутся в JS, а CSS генерируется в браузере во время работы (styled-components, Emotion).

**Zero-runtime CSS-in-JS**:
Стили пишутся в JS, а CSS извлекается в статические `.css`-файлы при сборке (Linaria).
_Avoid_: «вообще без JS» — у `styled` из Linaria остаётся маленький runtime-хелпер

**Consumer (потребитель)**:
Проект, который ставит библиотеку и импортирует из неё компонент.

**Peer dependency**:
Зависимость, которую библиотека не приносит сама, а ожидает у Consumer (React). Иначе в приложении окажутся две копии.

**Type declarations (`.d.ts`)**:
Файлы только с типами, без кода — контракт библиотеки для редактора и TypeScript у Consumer.

**Compound component**:
Компонент из нескольких частей (`Tabs`, `Tabs.List`, `Tabs.Tab`, `Tabs.Panel`), которые делят общее состояние.

**Controlled**:
Состоянием компонента владеет родитель: передаёт `value` и узнаёт об изменениях через `onChange`.

**Uncontrolled**:
Компонент сам хранит своё состояние; родитель задаёт только начальное — `defaultValue`.

**Design token**:
Именованное значение дизайна (цвет, отступ, радиус), на которое ссылаются компоненты вместо «сырых» значений.
_Avoid_: «переменная стиля»

**Theme (тема)**:
Набор значений для всех Design token (светлая, тёмная). Смена темы меняет значения, а не компоненты.
